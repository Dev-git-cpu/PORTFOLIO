# 🌐 Portfolio Website (Full Stack)

A full-stack personal portfolio website built to showcase my projects, technical skills, and professional profile.  
The application includes a modern frontend and a backend to manage data and APIs.

---

## 🚀 Features
- Fully responsive UI using Tailwind CSS
- Projects showcase with GitHub links
- Backend APIs for data handling
- Clean and modern design
- Mobile-first approach

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript
- HTML5

### Backend
- Java
- Spring Boot
- REST APIs

### Tools
- Git & GitHub
- IntelliJ IDEA / VS Code
